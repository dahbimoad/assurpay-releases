AssurPay Suivi Validations

Extension Firefox pour le suivi des validations faites sur le portail AXA

Cette page doit être ouverte dans Firefox. Copiez son adresse et collez-la dans Firefox.

Installer dans Firefox

Version 1.0.0 · signée par Mozilla · mises à jour automatiques

  1. Cliquez sur Installer dans Firefox.
  2. En haut de la fenêtre, cliquez Continuer l'installation, puis Ajouter.
  3. Cliquez sur la pièce de puzzle en haut à droite, puis sur l'épingle à côté de AssurPay Suivi Validations.

Outil interne d'AssurPay pour les agences. Ce n'est pas un produit d'AXA. Les données restent dans Firefox, sur l'ordinateur de l'agence.
